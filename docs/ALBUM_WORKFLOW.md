# Musicstudio — Release / Album Workflow

A musical work is larger than a track.

The canonical object is therefore a Release. A Release can be:

- single
- mini (for example three songs)
- EP
- LP
- live
- unplugged
- soundtrack

## A release has an arc

The Producer/Director can define:

- concept
- narrative
- stylistic rules
- emotional arc
- opening
- transitions
- interludes
- closing
- visual identity

## Example: three-song mini

01 INTRO / THEME
    establishes palette

02 MAIN SONG
    develops the theme

03 OUTRO
    resolves or leaves the listener somewhere new

The titles, key relationships, BPM trajectory, instrumentation, recurring motifs, sound palette and artwork can all contribute to coherence.

## Release-aware generation

A request can target:

- a new track inside an existing release
- an alternate version of a release track
- a transition between two tracks
- an interlude
- an intro/outro
- a live/unplugged reinterpretation

The Producer should be able to query the whole release before generating a part.

## Visual package

A finished release may include:

- cover
- back cover / track list
- booklet
- lyrics
- credits
- visualizer
- music video
- social snippets
- alternate artwork
- metadata and delivery package

Visual generation is connected to the release concept but remains a separate provider capability.

## Coherence checks

Future QA should be able to inspect:

- repeated or evolving motifs
- key and tempo relationships
- loudness continuity
- transition compatibility
- artwork consistency
- title/narrative consistency
- lyric themes
- instrumentation palette
- release duration

The point is not to force sameness. Coherence can include deliberate contrast.

## Direct / unplugged mode

Live and unplugged releases are first-class forms.

They can preserve songs while changing:

- instrumentation
- arrangement density
- room/ambience
- microphone/performance character
- transitions and audience space

These are separate release versions, not destructive replacements.
