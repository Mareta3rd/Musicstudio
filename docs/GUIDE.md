# Musicstudio — Creative Guide

The Guide is the small conversational entry point for turning an idea into a useful creative brief.

## Design

- one question at a time;
- short, open questions;
- no requirement to know musical jargon;
- optional questions only when useful;
- deterministic by default;
- no API or model is required;
- answers become durable project context later.

## Core sequence

1. intent — what should the work feel like or tell?
2. format — single, mini, EP, LP, live or unplugged?
3. world — what sonic universe?
4. reference — what reference and what part of it matters?
5. voice — who speaks and with what attitude?
6. energy — how should the energy evolve?
7. signature — what makes it recognizable quickly?
8. visual — what image/color/symbol belongs to it?
9. constraint — what must not happen?

The full sequence is a starting scaffold, not a rigid questionnaire.

## Future adaptive behavior

The Producer may reorder, skip or add questions based on the current release and project state.

Example:

An instrumental unplugged release should not be asked about vocal identity unless vocals are relevant.

A lyric-heavy project should trigger deeper prosody and singability questions.

An existing release should inherit known concept, palette, motif and narrative instead of asking again.

## Output

The Guide eventually produces a versioned Creative Brief that can be passed to the Producer and specialist team.
